# Circuit Pulse demo audio

`demo-pulse.wav` is generated deterministically by `scripts/generate-demo-audio.mjs`. It contains only synthesized percussion created for Over Nerv Block; it has no samples or third-party musical material.

- Title: Circuit Pulse
- Duration: 8 seconds
- Tempo: 120 BPM
- Format: mono PCM WAV, 22,050 Hz, 16-bit
- License: CC0-1.0 dedication for this project fixture

Regenerate with `npm run assets:demo`; verify byte-for-byte reproducibility with `npm run check:demo-audio`.
