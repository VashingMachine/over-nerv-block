- Idle Space dispatch returns `true`, meaning the event was not canceled.
- Space dispatched immediately after the visible playing readiness condition returns `false`, meaning active gameplay consumed and canceled it.
- Space dispatch after unmount returns `true`, proving cleanup and restored page behavior.

The existing ownership test still mounts two games, transfers playback, disposes and resets the former owner, and proves only the new active game scores Space (`RhythmGame.test.tsx:145-216`). The resulting design is small and readable: one listener, one latest-callback ref, one boolean consumption contract, and no second keyboard coordinator or speculative abstraction.
